QR skill flow: display or disk

One request takes one of two paths, display only or files on disk, and both end in a regular level M symbol.

display path: prompt to screen

The default path writes nothing. The symbol goes to stdout and the run exits 0.

disk path: prompt to files

Any of -o, --scale or --html implies --save; --title needs --html. The PNG is checked before its path is printed.

Both paths encode the same payload at level M; the viewer page caption is never part of the code.
